# 比纳案例 · 八人观点对照

围绕四个案例问题，整理八位同学的个人观点、共同认同与不同看法。

- 32组逐人观点、20项共同点、18组差异主题。
- 含完整原文核对、原始文件下载、展示模式与离线下载。
- 静态网页，无需后端或密钥。

## 展示入口

GitHub Pages 启用并部署完成后，展示地址为：https://aliyahodonnellsspc3-dotcom.github.io/lau/

## 发布设置

Settings → Pages → Deploy from a branch → main → /(root) → Save。

`.nojekyll` 用于直接发布静态文件。`index.html` 内置样式、脚本和原文文字；请保留 `sources/`，以支持下载原始文件。

## 内容边界

共同点标明支持范围，不将未提及当作反对。学生观点和历史叙述不等于独立核验的事实，原稿差异已在网页中注明。
